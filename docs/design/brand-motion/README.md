## 动作语汇

- 界面微状态：眨眼、观察、呼吸、连接、工作、归位。
- 品牌角色场景：走路、探头、起跳、睡眠、发现、庆祝、恢复。
- 角色性格：机灵、好奇、克制的小主编；视线通常先于身体动作。

## 不变量

- 白色 W 与眼睛保持正式 Logo 造型，不增加手、脚、嘴或其他器官。
- 白色身体始终是一条连续复合路径；两个底部尖角通过路径形变表现柔性短腿，不使用会露缝的裁切分层。
- 走路、向前位移和约 `-4px` 至 `+1px` 的重心起伏使用同一 `1.4s` 步态相位；落脚后保留短暂承重阶段，禁止滑步或整只弹跳。
- 眨眼使用独立的 `6.7s` 非同步周期，不机械绑定步频。
- 必须保留 `prefers-reduced-motion` 静止替代。
- 场景动作只允许变形或变换正式 Logo 自身，不新增手、腿、嘴、装饰物等第二套角色结构。
- 状态特效只用于补足明确语义：连接电流、工作任务卡/进度、归位对齐框、睡眠 `Zzz`、庆祝放射线；特效不改变角色解剖结构。
- 在目标尺寸下，动作应当不看标签也能识别；仅有数值变化而肉眼不可见视为失败。

这是品牌动效母版，不代表所有页面都应播放完整场景动作。产品接入只选择与用户状态一致的微状态，并继续复用正式 Logo 路径。
