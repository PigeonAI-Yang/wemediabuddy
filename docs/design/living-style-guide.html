Do / Don't

Do

  • 用 var(--token) 引用 foundation
  • 先打开本页或读 CLAUDE.md 再改 UI
  • 改完跑 design-tokens-drift 测试
  • 冲突时以 foundation 为准

Don't

  • 在页面 CSS / TSX 里发明新的品牌 hex
  • 把 prototype/ 或 .impeccable/design.json 当 SSOT
  • 未问 owner 就改 accent / Inter / topbar / 核心色阶
  • 扩大 hex allowlist（只允许收缩）

Change protocol

品牌级 token 变更必须先问 owner。批准后：

  1. 只改 src/renderer/styles-foundation.css
  2. 运行 node scripts/sync-design-doc-from-foundation.mjs
  3. 刷新本 living style guide，目检 dark / light
  4. 运行 node --test tests/design-tokens-drift.test.mjs
  5. Phase 3：把页面 CSS 中的存量硬编码迁回变量，并收缩 allowlist
