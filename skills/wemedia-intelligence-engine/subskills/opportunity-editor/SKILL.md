# Opportunity Editor

读取 [机会标准](../../references/opportunity-standard.md)，以真实性为硬门、传播价值为主目标。认知价值与实用价值均可入选，不为凑数量保留。

不要写成新闻摘要。每个机会给出：

- 对同一事实组生成事件层、用户层、产业/社会层三个语义不同的中心主张候选，记录事实/推断/观点类型、证据状态与边界、propagation_v2 分数、赢家和淘汰理由；
- 冻结一个处在具体情境中的读者与一个期望读者动作，使其服务赢家主张；认知型选题的动作可以是重新判断或转述，不强制伪造成即时操作；
- 命中五维哪一环（时代认知 / 个人方向 / AI 实践 / 公开验证 / 产品化）；
- 写 `title` 前在内部生成至少三个不同切口（具体问题 / 关键动作或方法 / 对象或证据冲突），选择最能被 sourceIds 兑现的一条；title 必须直白、可发布、不靠上下文就能读懂，包含题材独有信息，且必须包含一个可被正文兑现的利益/冲突钩子（数字/对比/反转/代价四选一，禁止把钩子全部卸载到 `titleGuidance`）；不得使用「普通人」等万能受众标签，不复用近期固定前缀与句式，不写来源未支持的数字、结果或因果；`titleGuidance` 仅用于补充角度/语气，不得用于卸载标题钩子；禁止血腥/身体/歧义比喻，如“说不出话”；
- 一个直接抛出冲突、反常识或机会的开头，且必须在正文首段即兑现标题钩子，不从背景/定义铺垫；
- 一个大胆、明确、属于我们的判断（保留可防守的张力，禁止软化为 `需要综合考虑/值得关注/未来可期`，有用细微差别须写明具体边界）；
- 支撑判断的事实（证据服务主张，不让证据罗列成为主体；抽象主张必须配人/场景/利害/后果）以及不能越过的边界；
- 书籍/经典方法仍需挂接真实实践或案例；纯模型、参数/价格新闻若揭示重大算力商业化、产业迁移、竞争格局或社会能力变化，可凭认知价值入选，不得强制降成产品测评；
- propagation_v2 固定六项：现实变化重要性25、冲突/认知缺口20、读者利害20、为何现在15、一句话可转述性15、账号适配5；真实性只做硬门，不计分；
- 先按事件实体和产业/社会关联读取知识上下文；只记录工具实际返回的固定版本引用，无相关结果则明确 `no_relevant_context`；
- `structureGuidance` 点名六栏目之一（迷茫诊断 / 经典方法 / AI 实战 / 项目日志 / 方向判断 / 商业化实验）并套骨架；
- 平台适配说明（若涉及小红书/视频等）：重写钩子/节奏/转藏评动机，不是缩短。

**编辑自检（选题即预检）：**真实性硬门通过后，检查现实变化、认知冲突、读者利害、为何现在与一句话转述性；即时行动不再是认知型选题的统一门槛。
可以把真实趋势和愿景拉近（中骗一个身位），不能虚构产品能力、案例、数字、收益、完成度或确定性。禁止自动发帖/躺赚叙事。
