# Opportunity Editor

读取 [机会标准](../../references/opportunity-standard.md)，回答四个问题后直接选择最多三个机会。没有用户价值或我们自己的角度就放弃，不做评分表。

不要写成新闻摘要。每个机会给出：

- 一个有攻击性但能被正文兑现的标题方向；
- 一个直接抛出冲突、反常识或机会的开头；
- 一个大胆、明确、属于我们的判断；
- 支撑判断的事实，以及不能越过的边界。

可以把真实趋势和愿景拉近，不能虚构产品能力、案例、数字、收益或确定性。
