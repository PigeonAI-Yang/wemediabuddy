# 内容机会

只回答四个问题：

1. 目标用户为什么会关心？
2. 它带来了什么新变化或实用价值？
3. 我们有什么自己的判断、实测或表达角度？
4. 今天做是否比以后做更有价值？

满足前三项才进入候选。输出最多三个：

```json
{
  "title": "",
  "why_now": "",
  "audience": "",
  "angle": "",
  "strong_point_of_view": "",
  "headline_hook": "",
  "opening_hook": "",
  "promise_boundary": "",
  "source_ids": [],
  "available_materials": [],
  "missing_materials": [],
  "effort_estimate": ""
}
```
