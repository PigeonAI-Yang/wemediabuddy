# 内容机会

最高目标：在真实性边界内最大化传播价值。真实性是准入硬门，不是传播分；认知价值与实用价值是并行入口。

1. 这件事改变了什么现实？优先识别规模、成本、供给、产业能力、竞争格局或社会行为的变化，而不是先问“能不能立刻拿来用”。
2. 谁会因此重新判断、行动或转述？认知变化、决策影响和可执行动作任一成立即可；冻结一个处在具体情境中的读者与一个期望动作，但它们必须服务中心主张，不得把产业/社会意义降成工具测评。
3. 我们有什么自己的判断、实测或表达角度？无实验/无观点的公告搬运不进机会；书籍/经典方法必须挂接主编的真实实践/案例与具体行动，书籍摘要与动机口号不进机会。
4. 今天做是否比以后做更有价值？必须写清具体窗口与错过成本（为何今天比明天值钱），否则视为未回答。

**传播型写作契约（与 `skills/evidence-grounded-writer/SKILL.md` §5 SSOT 一致，选题阶段即遵守）：**
- 每个机会只服务一个中心主张（标题、正文、证据围绕它）；
- 标题必须包含一个可被正文兑现的利益/冲突钩子（数字/对比/反转/代价四选一），禁止把钩子全部卸载到 `titleGuidance`；
- 开头必须立刻兑现钩子对应的冲突/利益点，不从背景/定义铺垫；
- 抽象主张在 `angle/pointOfView` 阶段即要求配人/场景/利害/后果；
- 保留可防守的张力，禁止自动软化为 `需要综合考虑/值得关注/未来可期` 等空话；有用细微差别须写明具体边界；
- 平台适配（小红书/视频等）是重写钩子/节奏/转藏评动机，不是缩短。

写 `title` 前必须在内部生成至少三个不同切口的候选：具体问题型、关键动作/方法型、对象/证据冲突型；再选择最能被 sourceIds 真实证据兑现的一条，只输出最终标题。`title` 必须直白、可发布、不依赖上下文，包含该题材独有的问题、动作、对象或证据，且必须包含上述钩子（数字/对比/反转/代价四选一）；不得使用「普通人」等万能受众标签，不得复用近期标题的固定前缀与句式，不得写入来源未支持的数字、结果或因果。`titleGuidance` 仅用于补充角度/语气，不得用于卸载本应在标题中的钩子。禁止血腥/身体/歧义比喻（如“说不出话”）。

每组事实先生成三个语义不同的候选中心主张：事件层、用户层、产业/社会层。逐条记录 `claimType`、`evidenceStatus`、`evidenceBoundary`、传播分和理由；最高传播价值候选若缺证据，保留并进入受控补料，不得自动换成安全小题。只有已支持的最高分候选可成为 winner，并与 `pointOfView` 完全一致。

传播分只按 `propagation_v2`：现实变化重要性25、冲突/认知缺口20、读者利害20、为何现在15、一句话可转述性15、账号适配5。事实核查不加分，只决定能否入选。纯模型、参数和价格新闻若揭示重大产业/社会变化可以直接入选，不要求必须变成即时个人行动；既无认知价值又无实用价值时才丢弃。

**反降级硬门：**可执行性、容易实验、容易产出回执不属于 `propagation_v2` 的独立分项。多来源已支持模型能力边界、长任务可靠性、成本结构、分发入口或竞争格局变化时，先比较“发布改变了什么旧判断、谁会重新决策”；不得仅因个人测试更容易落地，就让“先测三个任务 / 别开最高档 / 先试一次”等战术小题击败传播价值更高的认知主张。个人实测可作为正文证据、行动建议或后续选题，不能替代重大变化本身。

知识上下文必须先按事件实体与产业/社会关联两个维度查询。使用历史知识时记录真实固定版本引用；无相关上下文时记录 `no_relevant_context`。证据服务主张，不让证据罗列成为选题主体。

`structureGuidance` 必须点名六栏目之一（迷茫诊断 / 经典方法 / AI 实战 / 项目日志 / 方向判断 / 商业化实验）并套骨架：

- 迷茫诊断：人群原话/卡点 → 经典方法映射 → 主编实践/案例 → 行动与下一步
- 经典方法：框架/书籍出处 → 主编真实实践/案例 → 具体行动建议（无实践背书的摘要不单独成文）
- AI 实战：目标 → 动作 → AI 插手 → 卡点 → 回执 → 无效步骤 → 下一步
- 项目日志：今日一刀 → 回执 → 余味
- 方向判断：为何现在 → 强观点 → 标题/开头 → 来源
- 商业化实验（仅真实成交或失败）：场景 → 报价 → 过程 → 结果 → 教训

**编辑自检（选题即预检）：**真实性硬门通过后检查：(1)现实变化是否重要 (2)冲突/认知缺口是否具体 (3)读者利害与为何现在是否清楚 (4)能否一句话转述。即时行动不是所有认知型选题的强制项。
