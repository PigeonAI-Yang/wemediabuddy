# 内容机会

只回答四个问题，并点明商业化五维命中环：

1. 目标用户为什么会关心？（与「一个人 + AI 靠内容/产品活下去」哪一环相关：认知 / 技能 / 表达 / 获客 / 产品化）
2. 它带来了什么新变化或可动手的实用价值？
3. 我们有什么自己的判断、实测或表达角度？（无实验/无观点的公告搬运不进机会）
4. 今天做是否比以后做更有价值？

满足前三项才进入候选。说不出五维环节则降权或丢弃。需求信号仅当有重复问题信号时轻点，禁止硬造变现故事。全部合格候选都应输出；未达到门槛的线索只保留为资料，不为凑数量生成机会。

`structureGuidance` 必须点名六栏目之一并套骨架：

- 实验日志：目标 → 动作 → AI 插手 → 卡点 → 回执 → 无效步骤 → 下一步
- 开发日志：今日一刀 → 回执 → 余味
- 原则卡：判断 → 物证 → 边界 → 反例
- 机会判断：为何现在 → 强观点 → 标题/开头 → 来源
- 周复盘：兑现 → 图景 → 追问 → 重复问题 → 需求信号 → K/S/C
- 变现实验（仅真实成交或失败）：场景 → 报价 → 过程 → 结果 → 教训
