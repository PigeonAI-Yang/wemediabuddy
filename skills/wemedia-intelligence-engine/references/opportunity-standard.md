# 内容机会

只回答四个问题，并点明商业化五维命中环（时代认知 / 个人方向 / AI 实践 / 公开验证 / 产品化）：

1. 目标用户为什么会关心？目标用户是面对 AI 浪潮无所适从、想找到个人商业化方向并愿意完成真实项目的中文普通人；本机会把他们从迷茫推向明确方向、第一个真实项目或真实反馈中的哪一环（时代认知 / 个人方向 / AI 实践 / 公开验证 / 产品化）？
2. 它带来了什么新变化或可动手的实用价值？（对目标用户必须是可执行的决策/行动，不是行业谈资）
3. 我们有什么自己的判断、实测或表达角度？无实验/无观点的公告搬运不进机会；书籍/经典方法必须挂接主编的真实实践/案例与具体行动，书籍摘要与动机口号不进机会。
4. 今天做是否比以后做更有价值？

机会的 `title` 字段必须是直白、可发布、不依赖上下文就能读懂的中文标题；夸张、反常识、需要解释的爆点只放 `titleGuidance`，禁止血腥/身体/歧义比喻（如“说不出话”）。

满足前三项才进入候选。说不出五维环节则降权或丢弃。纯模型发布、参数/价格新闻只有翻译成新受众可执行的决策/行动并挂接个人商业化时才进内容。需求信号仅当有重复问题信号时轻点，禁止硬造变现故事。全部合格候选都应输出；未达到门槛的线索只保留为资料，不为凑数量生成机会。

证据 = 真实来源 + 主编实践/案例 + 具体行动；触达 ≠ 合格线索。

`structureGuidance` 必须点名六栏目之一（迷茫诊断 / 经典方法 / AI 实战 / 项目日志 / 方向判断 / 商业化实验）并套骨架：

- 迷茫诊断：人群原话/卡点 → 经典方法映射 → 主编实践/案例 → 行动与下一步
- 经典方法：框架/书籍出处 → 主编真实实践/案例 → 具体行动建议（无实践背书的摘要不单独成文）
- AI 实战：目标 → 动作 → AI 插手 → 卡点 → 回执 → 无效步骤 → 下一步
- 项目日志：今日一刀 → 回执 → 余味
- 方向判断：为何现在 → 强观点 → 标题/开头 → 来源
- 商业化实验（仅真实成交或失败）：场景 → 报价 → 过程 → 结果 → 教训
