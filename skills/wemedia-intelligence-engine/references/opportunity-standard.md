# 内容机会

只回答四个问题：

1. 目标用户为什么会关心？
2. 它带来了什么新变化或实用价值？
3. 我们有什么自己的判断、实测或表达角度？
4. 今天做是否比以后做更有价值？

满足前三项才进入候选。全部合格候选都应输出；未达到门槛的线索只保留为资料，不为凑数量生成机会：

{
  "title": "",
  "priority": 0,

}
