# 游戏资讯来源地图

最后人工核对：2026-08-02。来源用于发现与回原文，不代表每条内容都值得发布。

## A 级：平台官方

| 来源 | URL | 适用信息 |
| --- | --- | --- |
| Steam News Hub | https://store.steampowered.com/news/ | PC 游戏公告、更新和活动；具体结论继续打开对应游戏公告 |
| PlayStation Blog | https://blog.playstation.com/ | PlayStation 新作、State of Play、PS Plus 和版本信息 |
| Xbox Wire Announcements | https://news.xbox.com/en-us/announcements/ | Xbox、Game Pass、发布会和平台公告 |
| Nintendo News | https://www.nintendo.com/us/whatsnew/ | Nintendo 游戏、活动和数字发行动态 |
| Epic Games Store News | https://store.epicgames.com/news?lang=en-US | Epic 商店、PC 游戏和免费游戏动态 |

## A 级：发行商与开发商官方

| 来源 | URL | 适用信息 |
| --- | --- | --- |
| Ubisoft News | https://www.ubisoft.com/en-us/news | 新作、补丁、赛季、电竞和工作室公告 |
| EA News | https://www.ea.com/en-gb/news | EA 游戏、服务、开发和公司动态 |

具体游戏出现后，优先补充该游戏开发商、发行商、官方商店页、补丁页和官方账号，不把本表当成封闭名单。

## B 级：专业解释

- 使用有作者、日期和原始链接的专业媒体补充采访、实测与行业背景
- 涉及发行日、价格、平台、补丁内容或公司决定时必须回到 A 级或具体项目官方原文
- 财报与经营结论优先上市公司投资者关系页面和监管披露

## C 级：社区需求

- Reddit、Steam 社区、论坛、视频评论和公开社交讨论只用于发现玩家问题、争议和体验差异
- 热度、点赞和转发不证明事实正确
- 爆料、截图和匿名消息未获官方确认时必须标记传闻，不进入确定性标题

## 搜索组合

- `game title official release date update patch notes`
- `site:store.steampowered.com/news game title`
- `site:blog.playstation.com game title`
- `site:news.xbox.com game title`
- `site:nintendo.com game title news`
- `publisher game title official announcement`
