## Anti-Patterns Verdict

**LLM 评估**：不像一眼 AI 生成。黑夜紫罗兰身份真实、有纪律，今日页的机会简报是真编辑视角，品牌小动物有独立人格。最像模板的三处：①三页都有的 hero-metric 指标条（SaaS 驾驶舱反射，且撞自己的产品反参照「不做数据驾驶舱」）；②发现页幽灵大数字榜单（撞「无来源热度排行榜」反参照的气质）；③资料库同重卡片墙。

**确定性扫描**（detect.mjs，12 条）：真实发现 2 条——styles-foundation.css 字体栈以 Inter 打头（DESIGN.md 规定 Segoe UI/YaHei 单族，token 漂移）；styles-workflow.css `transition: width`（布局属性动画）。误报 10 条——1px 中性面板分隔线（栏间分隔，非彩色侧边条）与 Pi 对话内 markdown blockquote 的 3px 引文竖线（通用排版惯例，非卡片装饰条）。

**可视化叠加**：未注入。目标是需要保留工作状态的正式桌面应用窗口（CDP 直连），注入检测脚本会干扰在途工作；以 CLI 扫描 + 全页截图作为浏览器证据。

## Overall Impression

这是一个「已经有自己脸」的产品：克制的紫罗兰、编辑叙事、人机同场。它的问题不在品味，在**密度经济学**：指标条、卡片墙、双工具条把注意力摊薄了，而产品自己最珍视的「一个明确首选」原则在发现/资料/画布三页没有贯彻。最大的机会：让每一页像今日页一样先给出判断，再给证据。

## What's Working

1. **今日页机会简报**：入选理由→表达角度→核心观点→怎么讲，判断带理由、首选有最强层级——PRODUCT.md 的「私人主编」在这里完全成立。
2. **主题与 token 纪律**：双主题同构、紫罗兰基本只表达选择与主操作、状态色带文字（Status Is Semantic 落实）。
3. **Pi dock 人机同场**：贴边收起、宽度可拖、思考默认收起一行摘要、跨页不重建会话——AI 对话贴着业务现场，没有变成聊天首页。

## Priority Issues

- **[P1] hero-metric 指标条三页复用**（今日 86/4/5/10、创作 10/10/0/0/0/—、结果 3/2/2/1/1）。数字+小标签+同形卡，正是 SaaS 陈词，也撞自家反参照；大量 0 与 — 占首屏黄金位却不驱动下一步。修：改成一句可行动的摘要（「本周 3 篇发布，1 篇待复盘」）或并入分区标题行。建议命令：`$impeccable distill`
- **[P1] 发现页是无判断的榜单**。幽灵大数字 + repo 名 + 描述，没有回答「为什么值得你看」，行尾 `+/✎` 图标动作含义靠猜。修：每行带一句判断钩子（为什么/从哪来），图标动作换成文字按钮。建议命令：`$impeccable shape` + `$impeccable clarify`
- **[P2] 资料库同重卡片墙**。28 张卡一个重量，分组只有「观察中 · 28」，卡上看不到判断与来源类型。修：按主题/判断分组，卡面加来源类型与一句判断；或列表化。建议命令：`$impeccable layout`
- **[P2] 创作页格式栏 18 个图标钮**。`⌃ ⌄` 这类符号无法识别，违反最少选择。修：分组为主格式（B/I/S/链接）+ 插入菜单（表格/代码块/图片…），低频项收进菜单。建议命令：`$impeccable distill`
- **[P2] 内部语言泄漏到业务表面**。顶栏 `AI ·r1`（revision）、状态栏 `MCP 已连接`（工程缩写）——违反产品自己的 User Language Rule。修：`r1` 移除或改为工作空间资料名；`MCP 已连接` 改「Agent 服务已连接」并只在异常时强调。建议命令：`$impeccable clarify`

## Persona Red Flags

**Alex（效率型）**：资料库 28 卡只能逐张处理，无批量；榜单逐行收藏；看不到任何快捷键提示；创作列表 50/页但无跳转。核心路径（今日→创作）顺畅，旁路效率低。

**Jordan（新手）**：`+/✎`、`⌃ ⌄`、`0/3`、`重新发现` 四处都要猜；画布空场景两行工具条（8+ 动作）没有引导；MCP  jargon 出现在状态栏。大概率在发现页和画布页迷路。

**Sam（可访问性）**：行内图标钮部分有 aria-label（创作行动作有，榜单行未知）；幽灵数字装饰性大字号未确认 aria-hidden；状态栏秒针时钟每秒变化对屏幕阅读器是噪音；弱文字色在小字号下对比度存疑。

## Minor Observations

- 创作指标条「已归档 —」把未知计数渲染成缺失感；归档有数时应显示数字。
- 状态栏时钟带秒且每秒跳动：无状态意义的持续动效（产品禁令：装饰性动效）。
- 字体 token 与 DESIGN.md 漂移（Inter 打头 vs 规定 Segoe UI 单族）。
- `transition: width`（styles-workflow.css:255）：布局属性动画，Pi dock 场景可换 transform。
- 设置页「返回工作台」是低对比幽灵链接，逃生舱不够显眼。
- 发布页右栏混排平台账号与执行环境状态卡：发布前语境下可辩护，但执行环境在正常时应更弱。
- 主题页「判断 0」空状态文案是全站最好的空状态之一，值得作为范式推广。
- 白昼紫罗兰与黑夜同构、对比健康，亮色主题完成度高（截图确认）。
- 侧栏 active 态曾经疑似的双高亮经 DOM 验证为悬停残留，非 bug。

## Questions to Consider

- 如果每页的指标条都换成一句「下一步该做什么」的话，产品会不会更像主编而不是后台？
- 发现页的第一公民应该是「判断」还是「来源」？现在的页面答案似乎是后者。
- 资料库的核心动作是「找得到」还是「看得完」？28 张同重卡服务的是后者，用户需要的是前者吗？
