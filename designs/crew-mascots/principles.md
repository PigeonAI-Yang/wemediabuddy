# 调研提炼 · 角色家族设计原则（WMB 班组吉祥物）

来源：Line Friends / Kakao Friends / Duolingo / M&M's / Sanrio 的案例与设计系统文档（调研详见本轮会话记录）。以下为本项目采用的可执行原则：

1. **家族感靠统一画法，不靠同一物种/同一形体**。强制统一：圆角母形、无描边或同描边、眼睛画法、渲染风格；成员形体必须不同。（Kakao：狮/桃/鸭不同物种靠软圆角统一；Line：熊/兔/鸡靠圆与药丸母形统一）

2. **区分度三件套：一成员一主色（占 60%+）+ 剪影体型差 + 单一职能道具**。身体颜色必须承担角色识别，不允许全家同色机身；道具只留一个且直接暗示职能。（Kakao Ryan 黄/Apeach 粉；M&M's 一色一性格）

3. **每个角色只保留 1 个"记忆钩子"**（呆毛/耳朵/头饰），删掉一切不讲职能的装饰。廉价感来自随机加饰，高级感来自克制。（Sanrio 空白画布策略；Duolingo 形状语言）

4. **剪影测试是硬 gate**：五只填纯黑并排，靠外轮廓必须分得清谁是谁；不过关改外轮廓，不靠五官细节救。（Line 贴纸小尺寸可读性；Duolingo 角色规范）

5. **小尺寸变体**：识别特征放大 10–20%、负空间放大、装饰整层删除——不是等比缩小。（16px favicon 设计指南）

6. **材质克制提品相**：扁平板色 + 统一阴影画法；慎用渐变——用渐变掩盖结构是廉价感的来源。（Duolingo pill 阴影规范；Sanrio 批评分析）

## 对本轮设计的直接推论

- 上两轮"暖白机身全家同色"违反原则 2 -- 本轮每个角色机身带角色主色(60%+ 覆盖)。
- "终端屏脸 + 发光眼"作为统一画法 DNA 保留,但不再是唯一的区分手段。
- glyph 变体按原则 5 派生(特征放大,非等比缩小)。

## 修正（2026-08-20 复盘：彩虹分配是误读）

原则 2 曾被执行为"每角色一个彩虹色相"（蓝兔/绿刺猬/粉猫），成品被评为廉价地摊感。案例复核：Line/Kakao 成员多为**自然动物色**（棕熊/白兔/黄鸡），多彩是 M&M's 类糖果特例，不可迁移到动物家族。

修正口径：

- 主色 = 自然色或品牌色；家族共享 ≤1 个强调色；区分度主要靠剪影体型 + 记忆钩子，色彩只辅助。
- 渐变默认禁用（同色相喷枪渐变 = 廉价感来源），平涂为默认材质；美学系统由"车道打样"阶段经用户看图选定后量产，禁止执行者单方面决定。
