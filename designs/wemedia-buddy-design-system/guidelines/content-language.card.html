Content — 主编台语言

默认文案是中文用户语言；机器 ID、路径、revision、intent/state 代码一律进「技术详情」折叠区。产品名词全局共享一个 label map：页面标题 = 侧栏 = Pi 页标 = PRODUCT 房间名。

Do

  • 「今日可批 / 等你批 / 重新侦察 / 删除并归档」
  • 房间名照 PRODUCT C6：主编桌、前线、策划组提案夹、写字间、签发台、评报栏、关系墙
  • 一个公开小红书 MCP 标签；一个画布名（关系墙）
  • 空态给去向：「先去「发现」看看外面」

Don't

  • 「jobId #2847 状态 RUNNING」「mcp://… Bridge」「receipt 不存在」
  • 同一语义多个叫法（未处理/未解决、关系画布/知识网络）
  • 把「小红书 MCP / 外部 MCP / MCP Bridge」混用出三个标签
  • 技术词混进默认视图（browser-lock、DB 路径、skill 包名）

验收口令：若有人把 WMB 听成「自动发帖工具」或「又一个 AI 写作框」，说明叙事说歪了。
