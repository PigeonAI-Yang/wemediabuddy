# WMB-4965 Owner 操作清单（AI × 商业化成长）

配合：`.ai/2026-08-07-ai-commercialization-recipe-impl.md`、战略方案 `docs/spark/2026-08-07-ai-personal-commercialization-wmb-plan.md`。

## 1. 确认配方已升级

1. 启动 / 打开 AI 数据根（会走 `ensureOfficialWorkspaceProfile`）。
2. 设置 → 数据与存储 / 工作空间：显示名应为 **「AI × 商业化成长」**。
3. 跑一次今日情报或读编辑简报身份块：受众含「内容→信任→付费」，编辑简报含「五维」。

若仍显示旧「AI」：确认无 running 今日任务后重启应用再开根；仍旧则查 profile 是否非官方血统（自定义 profileId）。

## 2. 情报源增补（不写死 list_id）

在 **设置 → 情报渠道 / X Lists**（走现有 UI + 精确授权）：

| 方向 | 做什么 |
|---|---|
| 保留 | 现有 AI 前沿 List、官网 primary/release |
| 新增 List A | 独立开发者 / 一人公司（产品化与变现实验） |
| 新增 List B | AI 工具实测 / 工作流实测 |
| 官网（能配多少配多少） | 常用 API/模型定价页、独立开发者服务商公告 |

无 List 时主灯仍可跑；不要为凑源制造假 blocker。

## 3. 回执习惯（无新模块）

每次实验/开发结束后，任选其一留下回执：

- 资料库入库一条（标题=动作，摘要=结果+无效步骤+链接）
- 或内容项目 note / 版本说明

下周 Today 才可能把回执长成实验日志/原则卡。

## 4. 发布口径

| 平台 | 做法 |
|---|---|
| X | WMB 浏览器准备 → 你点发布 → 回执 |
| 小红书 | **客户端人工发布** + WMB 状态跟踪（90 天正式口径） |
| 公众号 | 现有文章准备路径；不强求日更 |

表现判断以 **X 指标** 为准；小红书/公众号用评论与私信原话喂复盘。

## 5. 复盘

每周一次 `wmb_save_review` / 结果页复盘，`summary` 追加：

```text
【商业化信号】
- 追问原话：
- 重复问题：
- 需求信号：
【本周】兑现 | 图景 | 五维偏科 | K/S/C
```

方法种子见 `.ai/commercialization-method-seeds.md`。

## 6. 14 天开跑（摘要）

- Day1 军令帖锁人设
- 每日：Today 四问 → 一栏目创作 → X 发布（可选）
- 每周：原则卡 + 周复盘
- 详见战略方案 §5

## 7. 明确不做

- 不为 List 硬编码 id
- 不开发小红书 prep（本阶段）
- 不把 WMB 说成自动发帖工具
